## Проект «Моя техника»

Небольшой личный каталог устройств. В нём можно добавлять, редактировать и удалять карточки, искать устройства и фильтровать их по категориям.

### Как открыть сайт

Откройте файл `index.html` в браузере двойным щелчком. Для работы проекта не нужны установка программ, сборка или подключение к интернету.

### Что умеет сайт

- Хранит каталог в localStorage этого браузера.
- Ищет по названию, модели, месту и заметкам.
- Фильтрует устройства по категории.
- Подстраивается под экран компьютера и телефона.

Данные localStorage доступны только в том же браузере и на том же устройстве, где вы их добавили.

### Файлы проекта

- `index.html` — структура страницы.
- `styles.css` — цвета, карточки и адаптация под экран.
- `app.js` — добавление, редактирование, удаление, поиск и сохранение.
